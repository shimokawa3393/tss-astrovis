# TSS-Mars 問題地図

> 火星で、ドローン・ローバー・Optimusを連携させる探査システムを、7つの課題に分けた全体地図 ・ 改訂 2026-10-25
> 各課題の詳しい中身は「Mars○○フェーズ(入門編)」、数値は [[TSS_定数表]] を参照

---

## 1. 飛行

**問題: 火星の大気でどうやって飛ぶか(大気密度は地球の約1/60、重力と合わせて揚力の確保は約23倍不利)**

| 細分化 | 必要な知識 |
|---|---|
| 薄い大気でのローター設計 | 流体力学、空気力学 |
| 推力と重力のバランス計算 | 流体力学、機体設計 |
| 火星の重力(約0.38G)への対応 | 力学、構造設計 |
| ローター形状・回転数の最適化 | 空気力学、材料力学 |
| 砂嵐のときに飛べるか | 気象工学、機体設計 |

## 2. 自律制御

**問題: 通信遅延(片道約3〜22分)の中で、完全自律をどう実現するか**

| 細分化 | 必要な知識 |
|---|---|
| 遅延前提の判断システム設計 | AI、制御工学 |
| 未知地形のリアルタイム認識 | コンピュータビジョン、SLAM |
| 障害物回避アルゴリズム | 経路計画、制御工学 |
| 異常検知・自己修復 | ソフトウェア工学 |
| 姿勢制御(火星環境) | PID制御、カルマンフィルター、慣性航法 |

## 3. 通信

**問題: ドローン・Optimus・地球の3点をつなぐ(毎日の途切れと、約2週間の太陽合)**

| 細分化 | 必要な知識 |
|---|---|
| 地球との長距離通信設計(中継機経由) | リンクバジェット、電磁気学 |
| Optimusへのデータ転送設計 | 通信工学、プロトコル設計 |
| 遅延込みのコマンド設計 | DTN、通信工学 |
| 砂嵐のときの通信途絶対策 | 通信工学、冗長設計 |
| 太陽合(約26か月ごと、約2週間)の通信途絶への備え | 通信工学、運用設計 |

## 4. 観測・センシング

**問題: 火星の地形と地下を正確に把握する**

| 細分化 | 必要な知識 |
|---|---|
| 3Dマッピング | LiDAR、点群処理、SLAM |
| 資源探索センサー(分光計・地中レーダー) | 分光学、センサー工学 |
| 居住可能エリアの判定基準 | 惑星科学、AI |

(Optimusへの地形データの受け渡しは、7. Optimus連携に移した)

## 5. 電力

**問題: 火星で長期間動き続ける電源(太陽光は地球の約43%、約590W/m²)**

| 細分化 | 必要な知識 |
|---|---|
| 太陽光パネルの発電量計算(火星: 約1.5AU) | 太陽エネルギー工学 |
| 砂嵐で発電がゼロになったときの対応 | 電力工学、バッテリー設計 |
| RTG採用の検討 | 核物理、熱電変換 |
| 消費電力の最小化 | 電気回路設計 |

## 6. 環境耐性

**問題: 火星の極限環境で壊れない機体を作る**

| 細分化 | 必要な知識 |
|---|---|
| 極低温(平均約−60℃、夜は−80℃以下)への対応 | 熱工学、材料力学 |
| 放射線耐性の設計 | 核物理、電子工学 |
| 砂嵐・砂塵への機械的対策 | 材料工学、機体設計 |
| 真空チャンバーでの試験設計(密度を火星に合わせる) | 実験工学 |

## 7. Optimus連携

**問題: ドローンをOptimusの目にする**

| 細分化 | 必要な知識 |
|---|---|
| 地形データの形式と受け渡し | データ工学、API設計 |
| Optimusの行動計画への統合 | ロボティクス、AI |
| リアルタイム更新の仕組み | 通信工学、ソフトウェア工学 |
| 連携プロトコルのオープン化 | OSS設計 |

## 改訂メモ(2026-10-25)

| 箇所 | 旧版 | 改訂版 | 理由 |
|---|---|---|---|
| 飛行 | 大気密度1% | 約1/60(地球の約1.6%)、揚力の確保は約23倍不利 | 密度 ÷ 61、重力 × 0.38 から計算 |
| 通信 | — | 太陽合(約26か月ごと、約2週間)の行を追加 | 遅延とは別の途切れ方 |
| 電力 | 火星: 1.5AU | 太陽光は地球の約43%(約590W/m²)を追加 | 1361 ÷ 1.524² で計算 |
| 自律制御 | PID制御、慣性航法 | カルマンフィルターを追加 | Mars自律制御フェーズに合わせた |
| 環境耐性 | 真空チャンバー | 密度を火星に合わせる、と追記 | 推力を決めるのは気圧ではなく密度 |
| 書式 | 絵文字の見出し、ASCII図 | 文字の見出し、Mermaid図 | 今風の書式 |
