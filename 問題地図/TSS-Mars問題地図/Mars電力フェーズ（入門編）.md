## 0. なぜ電力が重要か

火星ドローンのすべてのシステムは電力で動く。飛行、自律制御、通信、センシング、ヒーター。電力がなければ全部止まる。

しかも火星では、電力設計と機体設計が直結している。バッテリーを1g増やすたびに、飛行性能が削られる。550AUと違い、電力は「重量との戦い」でもある。

## 1. 太陽光パネルの発電量(火星: 約1.5AU)

逆二乗則による、各天体での太陽光の強さ:

| 距離 | 強さ | 地球比 |
|---|---|---|
| 1AU(地球) | 1,361W/m² | 1 |
| 約1.52AU(火星の平均) | 約590W/m² | 約0.43 |
| 5.2AU(木星) | 約50W/m² | 約1/27 |
| 550AU | 約0.0045W/m² | 約1/302,500 |

火星は地球の約43%。550AUとは桁が違い、太陽光はまだ使える距離にある。

ただし、火星の軌道は楕円なので、太陽からの距離が約1.38〜1.67AUで変わる。太陽光の強さも、季節によって約490〜710W/m²まで変わる。さらに、地表では空に舞う塵が光をさえぎるので、晴れていても宇宙空間の値より弱くなる。

## 2. 砂嵐で発電がゼロになる問題

火星の電力に固有の問題。550AUはRTGで安定しているが、火星では砂嵐で発電量が突然ほぼゼロになる「突然死」のリスクがある。砂嵐は数週間〜数か月続くこともある。

実際に、電力が原因で終わったミッションがある。

| 探査機 | 終わり方 |
|---|---|
| Opportunity(ローバー) | 2018年の火星全体を覆う砂嵐で発電できなくなり、交信が途絶えた |
| InSight(着陸機) | パネルに積もった塵で発電量が落ち続け、2022年に運用を終えた |

### 対策の方向性

| アプローチ | 中身 | 備考 |
|---|---|---|
| コーティング | 帯電防止で砂を付きにくくする | 可動部ゼロ、軽い |
| 静電除去 | 電気の力で砂を弾き飛ばす | 研究段階 |
| 交換フィルム | 保護フィルムを重ねて貼り、Optimusが剥がす | Optimus連携が前提 |
| バッテリーで延命 | 電気をためておき、サバイバルモードで乗り切る | 今のメイン |

### 砂嵐中のサバイバルモード

| 優先度 | 中身 |
|---|---|
| 1 | ヒーター(バッテリーを守る) |
| 2 | 通信(間欠送信で生存を知らせる) |
| 3以降 | 全停止(飛行・センシング・自律制御) |

## 3. RTGの検討と結論

| 比較項目 | 太陽光 | RTG |
|---|---|---|
| 砂嵐への強さ | ✗ ほぼゼロになる | ✓ 常に一定 |
| 重さ | 軽い | 約45kg(MMRTG、電気出力は約110W) |
| 調達 | 自由 | 作れる国が限られる(米国が中心) |
| コスト | 安い | 高い |

### 結論

**TSS-Marsは太陽光を極める。**

RTGは重さ・調達・コストの三重苦。プルトニウム238は、日本のスタートアップが調達できるものではない。しかも45kgのRTGは、ドローンには重すぎる(Ingenuityの全重量は約1.8kg)。

軽くて高効率なパネル(ペロブスカイトなど)の研究動向を追いながら、ソフトウェア側で砂嵐を乗り切る設計思想で進む。

## 4. 消費電力の最小化

火星では、「飛ぶためのエネルギー」と「生き残るためのエネルギー」を両方まかなう必要がある。

| システム | 地球のドローン | 火星のドローン |
|---|---|---|
| モーター | 最大 | 大 |
| ヒーター | ほぼゼロ | 大(夜は常時) |
| 通信 | 小 | 小 |
| センサー・CPU | 小 | 小 |

Ingenuityも、電力の多くを夜のヒーターに使っていた。

### 削れるもの

- 着陸中は観測機器を止める
- CPUのクロックを落とす
- 通信を間欠送信にする

### 1ソル(火星の1日)のサイクル

```
朝   : 太陽光で充電開始
昼   : 充電完了 → 飛行 → 観測
夕   : 着陸 → 観測機器を停止
夜   : ヒーターだけ動かして朝を待つ
翌朝 : 繰り返し
砂嵐 : サバイバルモードで延命
```

## 5. 550AUとの本質的な違い

| 項目 | TSS-550 | TSS-Mars |
|---|---|---|
| 電源 | RTG一択 | 太陽光 + バッテリー |
| 電力の安定性 | 常に一定(ゆっくり減る) | 砂嵐で突然ほぼゼロ |
| 重量の制約 | 比較的ゆるい | バッテリー1gが飛行性能に直結 |
| 設計思想 | 150年間、計画的に使い続ける | 生き残りながら動く |

## 一言まとめ

**TSS-550の電力設計は「長期間、安定して供給する技術」。**
**TSS-Marsの電力設計は「限られた電力で生き残る技術」。**
