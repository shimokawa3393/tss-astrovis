## 0. なぜ電力が重要か

探査機のあらゆるシステムは電力で動く。姿勢制御も、観測機器も、レーザー通信も、コンピュータも、機体を凍らせないヒーターも、電力がなければ全部止まる。

しかも550AUでは太陽光が使えない。地球から補給もできない。150年間、持っていった電源だけで動き続けなければいけない。電力は推進・通信・観測・自律制御の全てを支える基盤で、電力設計の失敗はミッション全体の失敗に直結する。

## 1. 太陽光パネルの限界距離

### 本質

太陽は全方向に光を放射している。光は球状に広がるので、距離が2倍になれば同じ光が4倍の面積に広がり、単位面積あたりの強さは1/4になる。これが逆二乗則。通信フェーズで電波の話として出てきたのと同じ原理が、光にもそのまま当てはまる。

### 太陽定数

地球軌道(1AU)での太陽光の強さを太陽定数と呼ぶ。約1,361W/m²で、大気圏外の1m²のパネルに毎秒1,361ジュールのエネルギーが降り注いでいるという意味。地上では大気による吸収・散乱で700〜1,000W/m²程度まで落ちるが、宇宙では大気がないのでこの値をそのまま使える。

### 基本式

$$E = \frac{1361}{d^2}$$

| 記号 | 意味 |
|---|---|
| $E$ | 太陽光の強さ(W/m²) |
| $d$ | 太陽からの距離(AU) |

### 各天体での値

| 距離 | 強さ | 地球比 |
|---|---|---|
| 1AU(地球) | 1,361W/m² | 1 |
| 約1.52AU(火星の平均) | 約590W/m² | 約0.43(約1/2.3) |
| 5.2AU(木星) | 約50W/m² | 約1/27 |
| 9.5AU(土星) | 約15W/m² | 約1/90 |
| 30AU(海王星) | 約1.5W/m² | 約1/900 |
| 550AU | 約0.0045W/m² | 約1/302,500 |

### 面積で押し切る限界

「パネルを大きくすれば解決できる」という発想は実際に使われている。木星探査機Junoは太陽光パネルの合計面積が約60m²ある。地球軌道の探査機なら2〜3m²で済むところを、20倍以上の面積で押し切って、木星(5.2AU)でも発電を成立させている。

ただし面積を増やすと、重量とコストが比例して増える。土星なら約90倍、海王星なら約900倍、550AUでは約30万倍の面積が要る。物理的に不可能な領域になる。

### 現実的な限界線

太陽光パネルが実用になる限界は、おおよそ5〜6AU、木星軌道がぎりぎりのライン。それより遠くへ行った探査機(Voyager・Pioneer・New Horizons・Cassini)が全部RTGを積んでいるのはこのため。

## 2. RTG(放射性同位体熱電気転換器)の設計

### 本質

RTGはRadioisotope Thermoelectric Generator。放射性物質が崩壊するときに出る熱を、電気に変える。可動部品がゼロで、燃料補給も太陽光も要らない。置いておくだけで数十年間電気を作り続ける。これがRTGの本質。

### 放射性崩壊とは何か

原子は陽子・中性子・電子でできている。同じ元素でも中性子の数が違うものを同位体(アイソトープ)と呼ぶ。不安定な同位体は自然に崩壊して別の元素に変わり、そのとき余分なエネルギーを熱や放射線として出す。これが放射性崩壊。RTGはこの「勝手に出てくる熱」を使う。

### なぜプルトニウム238を使うか

核兵器に使われるプルトニウム239とは別物。選ばれる理由は3つ。

| 理由 | 中身 |
|---|---|
| ① 半減期が87.7年 | 半減期は、放射性物質の量が半分になるまでの時間。短すぎると数年で使い物にならず、長すぎると単位時間あたりの発熱が少なすぎる。87.7年は数十年のミッションにちょうどいい |
| ② 熱出力密度が高い | 1kgあたり約560Wの熱を出す。他の候補より圧倒的に多い |
| ③ アルファ崩壊 | アルファ線は紙1枚で止まるほど透過力が弱い。薄い金属ケースで封じ込められるので、電子機器への影響が少なく、遮蔽の設計が楽になる |

### 熱電変換: ゼーベック効果

熱を直接電気に変える現象をゼーベック効果(Seebeck Effect)と呼ぶ。2種類の異なる金属(または半導体)をつないで、両端に温度差をつけると電圧が生まれる。

```
プルトニウム238(熱源・高温側)
    ↓ 熱
熱電変換素子(サーモカップル)
    ↓ 電気
探査機の電力系
    ↓ 廃熱
宇宙空間へ放射(低温側)
```

温度差が大きいほど発電量が増える。高温側はプルトニウムの崩壊熱で約500〜1,000℃(機種による)、低温側は宇宙への放熱で冷やす。この温度差が発電を支えている。

### 変換効率の問題

RTGの熱電変換効率は約6〜7%と、とても低い。熱の90%以上は電気にならず、廃熱になる。VoyagerのRTG(3基)は、打ち上げ時に熱出力が約7,000Wで、電気出力は約470Wだった。

ただしこの廃熱は、ただ捨てるのではなく、機体の内部に回して保温に使う設計になっている。RTGは電源であると同時に暖房でもある。

### Voyagerの電力の推移

| 項目 | 打ち上げ時(1977年) | 2020年代半ば |
|---|---|---|
| 電気出力 | 約470W | 約250W |
| 経過年数 | 0年 | 約47年 |

約47年で半分近くまで落ちている。原因は2つあって、プルトニウム238の崩壊による熱の減少と、熱電変換素子そのものの劣化。電力は毎年約4Wずつ減っていて、NASAはそれに合わせて機器を順番に止めている。

### 150年後に残る電力

プルトニウム238の崩壊だけを考えると、150年後の熱出力は

$$0.5^{150/87.7} \approx 0.31$$

で、約31%。これに熱電変換素子の劣化が加わるので、電気出力は30%より低くなる。

### プルトニウム238の調達問題

プルトニウム238は製造がとても難しい。原子炉でネプツニウム237に中性子を当てて作るが、アメリカは冷戦後に製造を止めていて、2010年代に再開したばかり。年間の生産目標は約1.5kgで、RTG 1基(MMRTG)に約4〜5kgが要る。製造量が需要に追いつかない状態が続いている。

### 改善の方向性

| 方向 | 中身 | 課題 |
|---|---|---|
| ① 変換効率を上げる(スターリング発電) | 熱 → 機械運動 → 電気。変換効率20〜30% | 可動部品があるので、150年間の信頼性が問題 |
| ① 変換効率を上げる(熱光起電力・TPV) | 熱を一度光に変えてから太陽電池で受ける。理論上20%超 | NASAが研究中 |
| ② 燃料を変える(アメリシウム241) | 半減期432年で長持ちする。150年ミッションと相性がいい。ESAが積極的に研究している | 重さあたりの熱出力がプルトニウム238の約1/5(約0.11W/g、Pu-238は約0.57W/g) |
| ③ RTGを複数積んで初期電力を大きくする | 150年後に30%に落ちても、絶対値として十分な電力が残る | 重量とコストが比例して増える |

現実的には①と③の組み合わせが有力。当面はプルトニウム238頼りが続く。

## 3. 消費電力の最小化

### 本質

RTGが捨てる廃熱とは別の話。電気になった後の数十Wを、どう使うかという問題。

探査機が電力を使う部分は大きく5つ。

- コンピュータ(状態機械・判断・データ処理)
- 姿勢制御(リアクションホイール・スラスタ)
- 観測機器(カメラ・センサー類)
- 通信(レーザー送信機・アンテナ駆動)
- 熱管理(機器を凍らせないためのヒーター)

### 電力バジェット設計

消費電力の最小化の核心はここ。「150年後に残る電力がX W」という前提で、全システムの合計がX W以内に収まるように設計する。予算管理と同じ発想。

たとえば150年後の残存電力を50Wと仮定すると:

| システム | 目標消費電力 |
|---|---|
| コンピュータ | 5W |
| 姿勢制御 | 15W |
| 観測機器 | 10W |
| レーザー通信 | 15W |
| ヒーター | 5W |
| **合計** | **50W** |

この配分を最初に決めて、各システムをその枠内に収める。どれか一つが予算オーバーすれば、別のシステムを削らないといけない。

### 機器そのものの消費電力を下げる

コンピュータの消費電力は、おおまかに

$$P \approx C V^2 f$$

で決まる($C$ は回路の容量、$V$ は動作電圧、$f$ は動作周波数)。電圧を下げる、周波数を下げる、回路を小さくする、のどれかで消費電力が落ちる。電圧は二乗で効くので、一番効く。

深宇宙向けには、RAD750という放射線耐性CPUが使われている(Curiosity・Perseverance・MROなど)。消費電力は約5W。スマホのCPUより遅いが、放射線で壊れないことを優先したトレードオフ。

### 使わないときは止める

最も効く手段。探査機のミッションを時系列で見ると:

| フェーズ | 必要な機器 | 止められる機器 |
|---|---|---|
| 巡航中(数十〜150年) | コンピュータ・姿勢制御・通信 | 観測機器 |
| 焦点到達後 | 全システム | なし |
| 異常時(セーフモード) | コンピュータ・通信のみ | 姿勢制御・観測 |

巡航中は観測機器をほぼ止められる。Voyagerも、電力の低下に合わせて科学機器を1つずつ止めている。

### 電力と熱管理の二重設計

RTGの廃熱を保温に使う設計は賢いが、問題もある。RTGの出力が落ちると、廃熱も減って、保温が追いつかなくなる。

だから、巡航中は廃熱で保温し、焦点到達後に電力消費が増えて余裕がなくなったら電気ヒーターで補う、という二段構えの設計が必要になる。電力と熱は切り離して考えられない。

### 550AUへの含意

消費電力の最小化は「永遠に動かすため」ではなく、「150年後の残存電力で観測フェーズを成立させるための逆算設計」が本質。

電力が豊富な初期に、どれだけ無駄を省いた設計ができるかが、観測フェーズの成否を決める。太陽帆などで巡航期間を数十年に縮められれば、残る電力は大きく増える(推進フェーズ)。

## 4. 全体のつながり

```
太陽光パネルの限界
  └─ 約5〜6AU以遠は現実的でない → RTGしか選択肢がない
        ↓
RTGの設計
  └─ プルトニウム238の崩壊熱 → 電気(約6〜7%)+ 廃熱(90%以上)
     廃熱 → 機体の保温に流用
     電力 → 時間とともに確実に減る(150年で約30%以下)
        ↓
消費電力の最小化
  └─ 残存電力から逆算して全システムの電力配分を設計
     使わない機器を止めるのが最も効く
     電力管理と熱管理は一体で設計する
```

電力フェーズの3つは独立した話ではなく、1本の因果の連鎖になっている。太陽が使えないからRTGになり、RTGが衰えるから消費を絞る。この順番で問題が決まっている。

今回やったのは入口だけ。各分野の下には大学の学科が丸ごと1個ある。

| 分野 | その下の層 |

全体の問題地図を手に入れた状態になった。深掘りする分野が出てきたとき、「あの話の下の層か」と繋げられる。
