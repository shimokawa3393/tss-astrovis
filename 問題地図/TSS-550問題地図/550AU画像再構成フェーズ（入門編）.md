## 0. なぜ画像再構成が必要か

SGLで系外惑星を撮るとき、探査機が受け取るのは「綺麗な惑星の写真」ではない。太陽の重力で曲げられ、引き伸ばされた光、つまり「歪んだ信号」だけが届く。

その信号から元の惑星の姿を復元する計算が、画像再構成。推進・通信・電力・自律制御がどれだけ完璧でも、この処理がなければ「データはある、絵が見えない」で終わる。

画像再構成はSGL探査の最終出口で、制御アルゴリズムと並んで自分が実際に手を動かす場所。

## 2. 逆問題とは何か

### 本質

「結果は分かる。でも原因が分からない」。これが逆問題(Inverse Problem)。

| | 中身 |
|---|---|
| 順問題(Forward Problem) | 原因が分かる → 結果を計算する |
| 逆問題(Inverse Problem) | 結果が分かる → 原因を推定する |

### モザイクで掴む

2×2の4ピクセルの平均値を1マスにする。これがモザイク処理(順問題)で、計算は簡単。

逆問題はその逆で、モザイクがかかった1マスの値から元の2×2を復元しようとする。

### なぜ難しいか

同じ平均値を作れる2×2の組み合わせは無数にある。どれが正解か一意に決まらない。これが逆問題の核心的な難しさ。

| モザイクの例 | SGLでは |
|---|---|
| モザイク処理 | 太陽重力レンズによる光の歪み |
| モザイク画像 | 探査機が受け取る信号 |
| 元の2×2 | 系外惑星の本来の姿 |

## 3. 畳み込みとPSF

### PSFとは

PSF(Point Spread Function・点広がり関数)は、「1点の光がどう広がるか」を表した関数。

懐中電灯を壁に当てると光が丸く広がる。その「広がり方の形」がPSF。モザイクで言えば、「2×2を平均して1マスにするルール」そのものがPSF。

### 畳み込みとは

$$\text{観測画像} = \text{元の画像} * \text{PSF}$$

($*$ は畳み込みの記号)

元の画像の各ピクセルに、PSFの形で「にじみ」を足していき、全ピクセル分を足し合わせたものが観測画像。Phase 1で推力カーブを時間で積分したのと、構造が似ている。

## 4. SGLのPSF

### 太陽重力レンズの原理と配置

一般相対性理論によれば、重力は時空を歪める。太陽の近くを通る光は曲げられ、太陽の向こう側から来た光が太陽の後ろ側に集まる。これが重力レンズ(Gravitational Lensing)。

```
系外惑星 →→→ [太陽] →→→ 探査機(548AUより先)
```

探査機は**太陽の方を向いて**、太陽の向こう側(探査機から見て太陽の真後ろ)にある系外惑星を見る。目標の惑星の反対側の空へ、探査機を送ることになる。

### 焦点距離の式

太陽の縁をかすめる光(通る位置 $b = R_\odot$)の焦点距離が最短になる。

$$F = \frac{b^2 c^2}{4 G M_\odot} \quad\Rightarrow\quad F_{min} = \frac{R_\odot^2 c^2}{4 G M_\odot} \approx 547.8\ \mathrm{AU}$$

| 記号 | 意味 |
|---|---|
| $b$ | 光が太陽の中心からどれだけ離れて通るか(衝突パラメータ) |
| $c$ | 光速 |
| $R_\odot$ | 太陽半径 |
| $G M_\odot$ | 太陽の重力定数 |

焦点距離は $b$ の二乗に比例するので、太陽から離れて通る光ほど遠くで集まる。だから焦点は点ではなく、547.8AUから外へずっと伸びる線(焦線)になる。普通の凸レンズとは、ここが違う。

### SGLのPSFが普通のレンズと違う点

| | PSFの形 |
|---|---|
| 普通のカメラレンズ | 中心が明るい丸い広がり |
| SGL | 探査機から見ると、像は太陽の周りのリング状(アインシュタインリング)になる |

系外惑星が太陽の真後ろにあると、光が太陽の縁を360度全方向からかすめて曲げられ、探査機に届く。だからリング状に見える。

もう一つの特徴は、PSFの裾がとても広いこと。普通のレンズよりずっとゆっくりしか暗くならないので、隣り合う画素の光が大きく混ざる。これが、復元が難しい一番の理由になる(Turyshevほか)。

### 増幅率(利得)

光軸の上では、光が大きく増幅される。

$$\mu_0 = \frac{4\pi^2 r_g}{\lambda}, \qquad r_g = \frac{2GM_\odot}{c^2} \approx 2.95\ \mathrm{km}$$

| 波長 | 増幅率 |
|---|---|
| 1µm(近赤外の光) | 約1.2×10¹¹倍(約111dB) |
| 3.6cm(Xバンドの電波) | 約3.3×10⁶倍(約65dB) |

この増幅が効くのは、**太陽の向こう側から来る光(観測)**だけ。探査機から地球への通信には効かない(通信フェーズ第7章)。

### 太陽コロナの雑音

太陽の縁ぎりぎりを通る光を使うので、コロナ(太陽の外層大気)の光をまともに受ける。これがSGLのSN比が低い大きな理由の一つ。

## 5. デコンボリューション

### やりたいこと

| | 式 | 状態 |
|---|---|---|
| 順問題 | 元の画像 $*$ PSF = 観測画像 | 計算できる |
| 逆問題 | 観測画像から元の画像を求める | これを解きたい |

PSFの畳み込みを取り除く操作を、デコンボリューション(Deconvolution)と呼ぶ。

### なぜ単純に割り算できないか

現実には観測データにノイズが乗っている。

$$\text{観測画像} = \text{元の画像} * \text{PSF} + \text{ノイズ}$$

単純に割り算(フーリエ空間での除算)をすると、ノイズが爆発的に増幅されて、ノイズだらけの画像になる。モザイクの復元で、元の2×2が無数にありうるのと同じ問題。

## 6. ノイズと正則化

### 正則化(Regularization)とは

「元の画像はそんなに急激に変化しないはず」という事前の知識(事前知識)を制約として加えて、解の候補を絞り込む技術。

### Tikhonov正則化(チホノフ正則化)

最も基本的な正則化手法。

$$\hat{x} = \arg\min_x \left\{ \| y - Hx \|^2 + \lambda \| x \|^2 \right\}$$

| 記号 | 意味 |
|---|---|
| $y$ | 観測画像 |
| $x$ | 推定する画像 |
| $H$ | PSFをかける操作 |
| $\arg\min$(アーグミン) | それを最小にする $x$ を求める |
| $\| \cdot \|^2$(ノルムの二乗) | 誤差の大きさ |
| $\lambda$(ラムダ) | 正則化パラメータ |

- 第1項: 観測データとの一致度
- 第2項: 解の大きさ・滑らかさへの制約

| $\lambda$ | 制約 | 結果 |
|---|---|---|
| 大きい | 強い | 滑らかだがぼやける |
| 小さい | 弱い | シャープだがノイズが出る |

PIDゲインのチューニングと同じ構造で、バランスを取るパラメータがある。

## 7. SGL固有の困難

### 像面のスキャン

普通のカメラは1枚撮れば画像が得られる。SGLは違う。

100光年先の地球型惑星の像は、焦線のまわりで直径約1.3km(650AU付近)の円の中に縮む(Turyshevほか)。探査機はこの円の中を、焦線に垂直な方向に少しずつ動きながら、1点ずつ明るさを測る。

しかもPSFの裾が広いので、1点で測る明るさには、狙った場所だけでなく惑星全体の光が混ざっている。全体を復元するには、多数の位置でのデータを組み合わせて逆問題を解く必要がある。

```
探査機の位置1 → 明るさ1(惑星全体の光が混ざっている)
探査機の位置2 → 明るさ2
探査機の位置3 → 明るさ3
      ↓
全部を組み合わせて逆問題を解く → 元の惑星の画像
```

MRIやCTスキャンと似た構造。体の周りから撮影して、断面の画像を計算で組み立てるのと同じ発想。

### 太陽の光を隠す

探査機は太陽の方を向くので、太陽そのものの光を隠すコロナグラフ(太陽の円盤を覆う装置)が必要になる。隠したあとに残るアインシュタインリングの光を測る。

### とても低いSN比

受け取れる信号はとても少なく、さらにコロナの光が混ざる。1回の測定ではSN比が1未満(ノイズの方が信号より大きい)になる可能性もある。

対処法:

- 長時間の積分(信号を積み重ねて、ノイズを平均化する)
- 統計的な推定(ベイズ推定)
- 事前知識の強力な活用

### 送れるデータ量の制約

通信フェーズで計算したとおり、550AUから地球へは電波で十数〜数十bpsしか送れない。測定データを全部送るのは難しいので、どこまでを探査機の中で処理・圧縮するかの設計が必要になる。

## 8. 全体のつながり

```
系外惑星の本来の姿
  ↓ 太陽重力レンズでリング状に歪む(PSF)
  ↓ コロナの光が乗る
探査機が受け取る信号(モザイク画像に相当)
  ↓ 像面を動きながら少しずつ集める(MRIに相当)
  ↓ 探査機の中で前処理・圧縮して地球へ送る
  ↓ デコンボリューションで逆問題を解く
  ↓ 正則化で解を絞り込む(λのチューニング)
元の惑星の姿を復元
```

画像再構成の品質は、通信フェーズに直結する。どれだけ信号を正確に、どれだけの量を届けられるかが、再構成の精度の上限を決める。5つの課題は全部つながっている。
