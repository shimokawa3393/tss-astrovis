# 550AU通信フェーズ（入門編）  
  
———  
  
TSS-550 通信フェーズ 入門編  
  
2026/05/04 現在  
  
0. なぜ通信が最重要か  
  
通信が成立しなければ、どれだけ優れた観測データを取っても地球に届かない。電力・推進・自律制御・観測、全部の成果が通信で初めて意味を持つ。  
  
通信は5つの課題の中で唯一、全ての前提になる。  
  
1. 問題の全体像  
  
① リンクバジェット設計   → 通信が物理的に成立するかの収支計算  
② アンテナの設計        → 信号を集中・増幅させる仕組み  
③ レーザー通信の指向精度  → 次世代通信手段と精度の問題  
④ 中継機チェーンの軌道設計 → 距離を分割して補う発想  
⑤ 遅延込みのプロトコル設計 → 76時間遅延前提の通信ルール  
  
  
2. リンクバジェット設計  
  
リンクバジェットとは  
信号の収支計算。送信側が「電力」を投資し、宇宙空間で「損失」として消え、受信側で残った量が雑音より大きければ通信成立。  
  
基本式（Friis伝達方程式・フリスでんたつほうていしき）  
  
P_r = P_t + G_t + G_r - L_fs - L_other  
  
P_r（ピー・アール）    = 受信電力（Receive）  
P_t（ピー・ティー）    = 送信電力（Transmit）  
G_t（ジー・ティー）    = 送信アンテナ利得（Gain・Transmit）  
G_r（ジー・アール）    = 受信アンテナ利得（Gain・Receive）  
L_fs（エル・エフエス） = 自由空間損失（Loss・Free Space）  
L_other（エル・アザー）= その他損失  
  
  
全部デシベル（dB）で計算するから、足し算・引き算だけ。  
  
添字の読み方ルール  
  
大文字 = 種類  
  P = 電力（Power）  
  G = 利得（Gain）  
  L = 損失（Loss）  
  
小文字添字 = 場面の説明  
  t  → transmit（送信側）  
  r  → receive（受信側）  
  fs → free space（自由空間）の頭文字2つ  
  
  
デシベル（dB）とは  
  
比率を表す単位。掛け算・割り算がdBの足し算・引き算に変換される。  
  
10dB  = 10倍  
20dB  = 100倍  
30dB  = 1000倍  
144dB = 2500兆倍  
  
  
3. 自由空間損失（L_fs・じゆうくうかんそんしつ）  
  
逆二乗則（ぎゃくにじょうそく）  
  
焚き火から離れると暖かさが薄まるのと同じ原理。  
  
電波は球状に広がる  
球の表面積 = 4πr²  
  
距離が2倍 → 表面積が4倍 → 受け取れる電力が1/4  
距離が10倍 → 表面積が100倍 → 電力が1/100  
  
  
計算式  
  
L_fs = 20log₁₀(d) + 20log₁₀(f) + 92.4  
  
d（ディー）         = 距離（km）  
f（エフ）           = 周波数（GHz）  
log₁₀（ログじゅう） = 「10を何乗すればその数になるか」を返す関数  
92.4               = 定数  
  
  
log₁₀はプログラミングのprint(x)と同じ構造。関数名がlog₁₀、引数がd・f。  
  
実際の損失  
  
Voyager（165AU） → 318.7 dB  
550AU            → 329 dB  
  
送信電力の10の33乗分の1しか届かない。  
  
  
4. アンテナ利得（G・ジー）  
  
本質  
  
懐中電灯の反射板と同じ原理。電力は増えていない。方向を絞っただけで、その先では強くなった。  
  
単位：dBi（デシベル・アイソトロピック）  
  
スマホアンテナ    →  2〜5 dBi  
八木アンテナ      → 10〜15 dBi  
パラボラ（小）    → 30〜40 dBi  
DSN（直径70m）   → 73 dBi  
  
  
計算式  
  
G = 10log₁₀（η × π² × D² / λ²）  
  
η（イータ） = 効率（0.5〜0.7）  
π（パイ）   = 円周率（3.14...）  
D（ディー） = アンテナ直径  
λ（ラムダ） = 波長  
  
  
直径が大きいほど、周波数が高いほど利得が上がる。  
  
5. 送信電力（P_t・ピー・ティー）  
  
単位：dBm（デシベル・ミリワット）  
  
1 mW  →  0 dBm  
1 W   → 30 dBm  
23 W  → 43.6 dBm（Voyagerの送信電力・電球1個分）  
  
  
宇宙では重量・電力・発熱の制約があるから、むやみに上げられない。  
  
6. 受信感度（Sensitivity・センシティビティ）  
  
本質  
  
周りの雑音が小さいほど弱い信号を拾える。  
  
宇宙の雑音  
  
熱雑音（ねつざつおん）              → 受信機の電子部品が熱で揺れる  
宇宙背景放射（うちゅうはいけいほうしゃ） → 宇宙全体に漂うノイズ  
太陽雑音（たいようざつおん）         → 太陽からの電磁波  
  
  
雑音電力の式  
  
N = k_B × T × B  
  
N（エヌ）            = 雑音電力（Noise）  
k_B（ケー・ボルツマン）= ボルツマン定数（1.38×10⁻²³）  
T（ティー）           = システム温度（K・ケルビン）  
B（ビー）             = 帯域幅（Hz・ヘルツ）  
  
  
DSNは受信機を20K（約−253℃）まで冷やして雑音を最小化している。  
  
S/N比（エスエヌひ）  
  
S/N = 信号（Signal） / 雑音（Noise）  
  
1より大きい → 通信成立  
1より小さい → 雑音に埋もれて聞こえない  
  
  
7. 550AUの通信は可能か  
  
現状の収支  
  
送信電力（23W）          → +43.6 dBm  
送信アンテナ利得          → +48 dBi  
受信アンテナ利得（DSN70m） → +73 dBi  
受信機低雑音化            → +20 dB  
自由空間損失（550AU）     → −329 dB  
────────────────────────  
合計                     → −144 dB（足りない）  
  
  
3つの解決策  
  
① データレートを極限まで下げる  
   Voyagerは1秒間に数百ビットまで絞って通信成立  
  
② レーザー通信に切り替える  
   電波（8.4 GHz）→ レーザー（300 THz）  
   周波数が約3万倍 → 利得が圧倒的に上がる  
  
③ SGL（太陽重力レンズ）を受信アンテナにする  
   太陽の重力が電波を集めて焦点が550AU  
   = 探査機の目的地そのもの  
   理論上の利得：+60〜90 dB  
  
  
最終収支  
  
これまでの収支   → −144 dB  
SGL利得         → +70 dB  
レーザー通信     → +50 dB  
データレート削減  → +30 dB  
────────────────────────  
最終収支         → +6 dB（通信成立）  
  
  
目的地と手段が一致している。550AUにいることが、そのまま最強の受信設備になる。  
  
8. 電磁波とアンテナの基礎  
  
電磁波とは  
  
電場（でんば）と磁場（じば）が交互に振動しながら空間を伝わるもの。光・電波・X線は全部同じもので周波数が違うだけ。  
  
電磁波の周波数帯  
  
AM/FMラジオ → MHz（メガヘルツ）  
WiFi        → 2.4〜5 GHz（ギガヘルツ）  
Xバンド     → 8.4 GHz（深宇宙通信）  
光・レーザー → 300 THz（テラヘルツ）  
  
  
アンテナの動作原理  
  
送信 = 電気 → 電波（電流を流すと電磁波が飛び出す）  
受信 = 電波 → 電気（電磁波が当たると電流が生まれる）  
  
  
波長（λ・ラムダ）の計算式  
  
λ = c / f  
  
c（シー） = 光速（3×10⁸ m/s）  
f（エフ） = 周波数  
  
  
最適なアンテナの長さ（半波長ダイポール）  
  
L = λ / 2  
  
Xバンド（8.4 GHz）の場合：3.6cm / 2 = 1.8cm  
  
  
パラボラアンテナとSGLの共通点  
  
              反射・屈折させるもの   集まる場所  
パラボラアンテナ → 金属のお椀        → 焦点（数cm先）  
SGL            → 太陽の重力         → 焦点（550AU）  
  
原理は同じ。太陽が巨大なパラボラアンテナになっている。  
  
  
9. 指向性（しこうせい）  
  
ビーム幅（θ・シータ）の式  
  
θ = 70 × λ / D  
  
Voyager（3.7m）のビーム幅：  
θ = 70 × 0.036 / 3.7 = 0.68°  
  
満月の見かけの大きさ → 0.5°  
Voyagerのビーム幅   → 0.68°  
DSN（70m級）        → 0.007°  
  
  
遅延問題  
  
550AUから地球まで → 約76時間（約3.2日）  
修正命令が届くまで → さらに約76時間  
合計              → 約152時間（約6.4日）後にやっと修正できる  
  
→ 自律制御が必須になる理由がここにある。  
  
  
10. レーザー通信の指向精度  
  
ビーム幅の比較  
  
Voyager電波（3.7m） → 0.68°  
レーザー通信        → 0.000003°（電波の約20万分の1）  
  
  
3つの問題  
  
① 探査機の振動  → 微細な揺れがそのままズレになる  
② 光行差        → 地球が動いてるから先読みして打たないといけない  
③ 76時間の遅延  → 届いた時には地球が別の場所にいる  
  
  
光行差（こうぎょうさ）  
  
雨の中を走ると前から降ってくるように見えるのと同じ原理。  
76時間で地球が動く距離 = 約817万km（公転速度 約30km/s × 約27万秒）  
→ その分だけ先読みして打つ。  
  
  
解決策：APTシステム  
  
A = Acquisition（アクイジション）= 捕捉（ほそく）→ 相手を見つける  
P = Pointing（ポインティング）  = 指向（しこう）→ 正確に向ける  
T = Tracking（トラッキング）    = 追尾（ついび）→ 向け続ける  
  
仕組み：  
地球からビーコン（目印の光）を送る  
→ 探査機がビーコンを検出する  
→ ビーコンを基準に自動補正し続ける  
  
  
11. 中継機チェーンの軌道設計  
  
発想  
  
探査機（550AU）  
    ↓  
中継機A（200AU付近）  
    ↓  
中継機B（50AU付近）  
    ↓  
地球  
  
  
ラグランジュ点（ラグランジュてん）  
  
2つの天体の重力がつり合って、軌道維持コストがほぼゼロになる特別な場所。中継機を置くのに最適。  
  
現実的な評価  
  
550AUまでの中継機チェーン → 現時点では非現実的  
  
現実解：  
① 直接通信 → レーザー + SGL利用で中継なしで成立  
② 近傍中継 → 地球から100AU以内だけ中継機を使う  
  
  
12. 遅延込みのプロトコル設計  
  
普通のインターネット（TCP）の問題  
  
探査機：「データ送ったよ」  
        ↓ 76時間後  
地球：  「受け取ったよ」（ACK・アック）  
        ↓ 76時間後  
探査機：「じゃあ次のデータ送るね」  
  
→ 1回のやり取りに約152時間（約6.4日）。使い物にならない。  
  
  
解決策：DTN（ディーティーエヌ）  
  
DTN = Delay Tolerant Networking（ディレイ・トレラント・ネットワーキング）  
日本語：遅延耐性ネットワーク（ちえんたいせいネットワーク）  
  
確認を待つのをやめる。  
「届いたかどうか確認しない」  
「とにかく送り続ける」  
「途中で保存して、繋がったときに転送する」  
= ストア・アンド・フォワード（Store and Forward）  
  
普通のインターネット → 速達（届いたか確認してから次を書く）  
DTN               → 普通郵便（投函したら確認しない）  
  
  
バンドルプロトコル（Bundle Protocol）  
  
バンドルの中身：  
  宛先（どこに届けるか）  
  有効期限（いつまで有効か）  
  優先度（どれを先に送るか）  
  データ本体  
  
  
エラー訂正（Error Correction）  
  
宇宙放射線でビット（0と1）が勝手に反転する。  
  
Reed-Solomon（リード・ソロモン） → CDやDVDでも使われてる  
LDPC（エルディーピーシー）      → 現代の深宇宙通信の標準  
Turbo Code（ターボコード）      → 携帯電話でも使われてる  
  
  
13. 全体のつながり  
  
リンクバジェット  
    ↓ 損失を計算したら  
アンテナ利得 + 送信電力 + 受信感度 で補う  
    ↓ それでも足りないから  
レーザー通信 + SGL + データレート削減 で成立させる  
    ↓ レーザーは細すぎるから  
APTシステムで自律追尾  
    ↓ 遅延があるから自律が必要  
自律制御（5つの課題の1つ）につながる  
    ↓ 通信ルールは  
DTNプロトコル + エラー訂正で成立させる  
  
  
5つの課題（推進・通信・観測・電力・自律制御）は全部つながっている。  
  
14. 記号・用語まとめ  
  
ギリシャ文字  
  
λ（ラムダ） → 波長  
π（パイ）   → 円周率（3.14...）  
η（イータ） → 効率  
θ（シータ） → 角度・ビーム幅  
  
  
単位  
  
dB（デシベル）                   → 比率を表す単位  
dBm（デシベル・ミリワット）        → 電力の比率（1mW基準）  
dBi（デシベル・アイソトロピック）   → アンテナ利得の比率  
Hz（ヘルツ）                     → 周波数  
GHz（ギガヘルツ）                 → 10億Hz  
THz（テラヘルツ）                 → 1兆Hz  
K（ケルビン）                    → 温度（℃ + 273）  
AU（天文単位）                   → 地球〜太陽間の距離（約1.5億km）  
bps（ビーピーエス）               → データレート（1秒間に何ビット送れるか）  
  
  
fの読み方ルール  
  
式の本体に単独で立っている → 変数（例：周波数）  
添字に入っている          → 略語（例：L_fsのfs = Free Space）  
f(x)の形                 → ファンクション名
