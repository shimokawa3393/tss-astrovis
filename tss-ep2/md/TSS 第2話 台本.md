# TSS Astrovis 第2話 台本「太陽を囲む輪」

テロップの「/」は改行。テロップは読点・句点なし。

---

## メタデータ

- シリーズ名: TSS Astrovis
- 話数: 第2話
- 関連するTSSの章: 550AU画像再構成(SGLの像の形)
- タイトル: 太陽を囲む輪
- テーマ: 探査機の望遠鏡では、系外惑星の光は太陽を囲む細い輪になる。輪は太陽のすぐそばにあり、太陽が眩しすぎるので隠さないと見えない。
- 見せ方: A(カメラワーク型)。前半は引きで配置、後半は探査機の視点。
- 伝え方: ③隠れた主役型(「輪が見えるはず」→「太陽に埋もれる」)
- 絵作りの方針: 第1話と同じ黒背景と発光線。数式は出さず、テロップだけで進める。
- 想定尺: 約39秒 / 総フレーム: 1170(30fps)/ **総カット数 n = 7**
- 安全領域: 第1話と同じ。

## 実物/模式化の決定

| 項目 | 実物どおり | 模式化・誇張 | 明記方法 |
|---|---|---|---|
| 配置(探査機・太陽・惑星が一直線) | 一直線 | 距離は縮めて描く | 投稿文に「距離は縮めて描画」 |
| 探査機の距離 | 1200AU(第1話の4aと同じ。輪の見た目をそろえる) | | 出さない(画面にも投稿文にも) |
| 輪の半径 | 太陽のすぐそば(太陽半径の約1.48倍、1200AUの場合) | | なし |
| 輪の太さ・明るさ | | 見えるよう太く、明るく描く | 投稿文に「輪は見やすく強調」 |
| 探査機・惑星 | | 記号的な形 | 投稿文に「イメージ」 |

## 使う数値と出典

| 数値 | 値 | 出典・検算 |
|---|---|---|
| 輪が太陽のすぐそばにあること | 輪の半径 $b=\sqrt{2 r_g d}$。547.8AUで太陽半径の1.00倍、1200AUで1.48倍(角半径は約1.18秒角、太陽は約0.80秒角) | 制作側の検算(`physics_ring.py`、TSS_定数表の値と一致) |
| 輪の光を測る、太陽を隠す装置 | コロナグラフ | 550AU画像再構成フェーズ第7章(Turyshevほか) |
| 惑星の像は輪の形になる | 太陽の真後ろの光が全周から曲がって届く | 同第4章 |

画面に数字は出さない。探査機の距離(AU)は投稿文にも出さない(ユーザー「なーんだ、生きてるうちに実現しないじゃーんな」ってなると嫌だから)。

## 精度に関する注意

- 輪になるのは、探査機・太陽・惑星がほぼ一直線のとき。
- 惑星のそばの恒星の光もレンズされるはずだが、この回では扱わない。「惑星の光も輪になって届く」と言い、輪が惑星の光だけでできているとは言わない。
- 実際の輪は一様ではなく、とても薄くなる。絵は見やすく強調しているので、投稿文に明記する。

## カット構成(起承転結)

### ①起 — 使用カット数: 2

**c00(3秒 / 90フレーム)**
- scene: 星だけの宇宙。
- テロップ(中央): 太陽は / 巨大なレンズになる
- どの回から見ても分かるよう、最初のテロップで前提を言う(ユーザー「入りが唐突すぎる」「理想はどの動画から見ても違和感がない動画」)。問いかけ(「太陽の向こうの惑星を / 撮ることはできるか」)と短い前提の2案から、この回は前提が一言で足りるので短い前提。最初と最後のテロップは中央・星だけの背景(TSS 台本フォーマットに追加)。

**c01(5秒 / 150フレーム)**
- scene: 横から見た引きの絵。左に探査機、中央に太陽、右の遠くに小さな光(系外惑星)。3つが一直線に並ぶ。
- テロップ: 探査機と太陽と惑星が / 一直線に並ぶ
- つなぎ: 最後は一直線の配置。

### ②承 — 使用カット数: 1

**c02(6秒 / 180フレーム)**
- scene: 惑星の光が太陽の周りに広がり、上下左右ぜんぶの方向から曲がって、探査機に集まる(円錐状)。カメラは真横のまま動かさない(見下ろす案は、カメラが回るのと光が伸びるのが重なり背景も流れたのでやめた)。(軸方向から見た図を挟む案は、描いてみると光の筋が絡まって輪に見えなかったのでやめた。輪はc03で見せる)
- テロップ: 光は太陽の周りの / ぜんぶの方向から / 曲がって届く
- 模式化: 距離は縮める。
- つなぎ: 最後は光が探査機に集まった絵。

### ③転 — 使用カット数: 2

**c03(9秒 / 270フレーム)**
- scene: 第1話の4aを踏襲する。探査機の後ろ上から太陽の方を見る。目で見た太陽は明るい点(1200AUでは見かけの直径約1.6秒角で、円盤には見えない)。その点から「望遠鏡の視野」の円が開き、視野の中に太陽の円盤と、そのすぐ外の細い光の輪。c04・c05もこの視野の中で進める(c05は視野の上に惑星のイメージを足す)。
- テロップ: 探査機の望遠鏡では / 太陽を囲む細い輪 → この輪を / アインシュタインリング / と呼ぶ
- 名前: 輪が出たところで説明する(ユーザー「輪が登場してるのに説明が遅い」。最初はc06で説明していた)。そのぶん7秒→9秒。名前のテロップは3行(1行にすると14文字で上限を超える)。一度は、視野の右上に小さな目印で添える形にした(コードは `draw.build_ring_label`)が、テロップで説明するので出さない。
- つなぎ: 最後は円盤と輪が並んだ絵。

**c04(7秒 / 210フレーム)**
- scene: 太陽の光がにじんで広がり、輪がその中に埋もれて消える。そこに黒い円(コロナグラフ)が円盤を覆う。隠してもコロナのもやは残り、その中に細い輪がうっすら見えてくる(くっきり浮かぶとは描かない。主な雑音は太陽のコロナ: Turyshev & Toth 2022)。
- テロップ: でも太陽が眩しすぎる / 隠してやっと見える
- つなぎ: 最後は、太陽を隠して輪だけが見える絵。

### ④結 — 使用カット数: 2

**c05(6秒 / 180フレーム)**
- scene: 視野の中の輪(c04の最後)の上に、狙った惑星を小さく出す(太陽の真後ろで見えないので、イメージとして)。惑星のあちこち(海・陸・雲)から細い光の筋が出て、どの点の光も輪の全周に広がって入る。「惑星全体の光が、この1本の輪に混ざっている」を見せる。
- 精度: 輪の位置と惑星の場所は1対1に対応しない(輪を見ても模様は分からない)。筋は特定の点から輪の特定の場所へ向かわせず、輪全体へ広げる。
- テロップ: 惑星の光も / この輪になって届く
- つなぎ: 最後は輪だけの絵。

**c06(3秒 / 90フレーム)**
- scene: 星だけの宇宙(c05から切り替える)。テロップは中央(最後のテロップの決まり)。
- テロップ: この輪から / 惑星の像を再構成する
- 名前で締めない: 最後に名前を出すと、言い方を変えても決めゼリフになる(ユーザー「これを…と言うで決めるのはダサい」「結局アインシュタインリングでキメてるじゃん」)。名前の説明は要る(ユーザー「やっぱりアインシュタインリングの説明はいるな」)ので、c03で輪が出たところで説明し、最後は再構成のテロップで終える。
- 次回への引き: 輪1つでは画像にならず、像面を動きながら集めて逆問題を解く(問題地図「550AU画像再構成フェーズ」第7章)。第3話へ

**総カット数 n = 7** / 合計 39秒 / 1170フレーム

## 投稿文(案)

タイトル: 太陽を囲む輪

本文:

系外惑星が太陽の真後ろにあると
光は太陽の周りをぐるっと回って届く
探査機が見るのは、太陽を囲む細い輪

ただし輪は太陽のすぐそば
太陽が眩しすぎて、隠さないと見えない

アインシュタインリング
太陽重力レンズの像の形

※距離は縮めて描いています
※輪は見やすく強調しています
※探査機と惑星はイメージです
※構想・研究段階の内容です
