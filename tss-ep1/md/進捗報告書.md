## 決めたこと

### 全体の見た目
- 黒背景、NASA SVS の実際の星だけ（天の川なし）。光線は細い（約1px）暗い金色、焦線は太く明るく下ほど明るい
- 色の変換は Standard（AgX は明るい太陽のオレンジがピンクに抜けた）
- 光線は交わってから800AUで消す（白く太い線で交差を全部残すと込み合って、焦線が埋もれた）

### 太陽
- Solar System Scope の実写テクスチャ（ユーザー指定「リアルなテクスチャ」）。中心を黄色、縁を濃いオレンジ（周辺減光）
- まわりは筋のない、なめらかな光のにじみ（縁から太陽半径の1.6倍まで、明るさ0.6）
  - ノイズで外向きの筋を入れたコロナは「このコロナはないわ笑」
  - 2.5倍・明るさ1.2は「もう少し抑え気味で」
- 大きさは記号的。2a・3aは一番内側の光線にちょうど接する大きさ（b=R の0.85倍）。3bだけ半径45pxの記号（3万倍の円を3bの縮尺で描くと半径約100AU分になり、海王星が太陽の中に入る）

### 光線の形
- 上では計算どおり x = b、軸とは焦点距離ちょうどで交わり、その間を太陽の脇で幅 b のなめらかなカーブでつなぐ（`scene.ray_x`）
- 最初は太陽の高さで折っていたが、2aで寄ると、折れた先が太陽の円に食い込み、光が太陽の中を通って下から出てくるように見えた
- 間引き: 2aは片側5本（b = 1〜3R）、3aは片側13本（b = 1〜3R）、3bは縁の近く（b = 1.00〜1.12R を0.02Rおき。548AUの時点で画面に入るのはこの範囲だけ）

### 各カットの配置
- 1a: レンズの中心は上から45%（2aの太陽と同じ）、光が集まる点は上から80%（2aの一番内側の光が軸に近づく高さ）
- 2a: 太陽の円の半径144px、中心は上から45%
- 3a: 太陽〜5000AUを画面の上28%〜85%に入れる。最初は上12%からだったが、ドラフトでテロップ（上から約11%）が太陽に重なったので下げた（11-01）
- 3b: 窓（画面の高さ）200AU、いまの深さは上から55%。1フレームで2.28AU（22px）。目盛りは10AUごとに短い線、100AUごとに長い線と「100 AU」。海王星は軸の脇に置いた距離の目印（ラベルは「海王星」だけ、数字なし）。手前の斜め上から照らす（上からだけだと細い三日月になった）
- 4b: 望遠鏡の視野の円（半径380px、中心は上から60%）。惑星は架空の惑星を画面の格子にそろえたモザイク。光は正面寄りの左上から
  - 架空の惑星（11-01）: 球の上の向きのノイズで、赤茶と黄土の大陸、暗い青緑の海、横に流れる筋の雲、小さな極の氷（`props.PLANET_*`）。地図の画像は使わない
  - 経緯: 地球の画像（アフリカが正面 →「日本中心に」→「日本がちょい右」）→ ユーザー「地球以外って描写できる？未知の惑星感を出したい」。論文は地球の画像で試算している（投稿文に）
  - 「アップで宇宙人が手を振る」案は見送り: 1000×1000画素では1画素が約13km四方で、人や建物は見えない

- 4a（11-01）: 探査機の後ろ上から太陽の方を見る（縦の画角60°）。探査機は太陽の点の下の少し右（右端はSNSのボタンがかぶる）
  - ドラフトで3行のテロップと視野がぶつかったので、視野の中心を上から40%（760px）、太陽の点を62%に下げた
  - 目で見た太陽は明るい点。1200AUでは見かけの直径約1.6秒角・約-11等で、円盤には見えない
  - 点の脇に小さく「太陽」（海王星と同じ書き方）。動画では、この点から視野がピュッと開く（ユーザー「『これが太陽』とか、小さな恒星から拡大図がピュッて出すかすればオッケー」）
    - 最初の試作は太陽を半径70pxの円盤にして、まわりに輪を描いた。「いいじゃん！」の後にユーザー「リアルな話、太陽こんなに大きく見えないでしょ？」→ 点にした
  - 太陽の円盤と光の輪は、上の「望遠鏡の視野」（4bと同じ細い円、半径210px）の中に描き、太陽の点から円に接する2本の線でつなぐ。口径1m（波長1µmで約0.25秒角）なら分けて見える。4bの視野へもつながる
  - 光の輪の半径は太陽の1.48倍。1200AUで輪を作る光線は b = R√(1200/548) なので、この比だけは実物どおり（`props.einstein_ring_ratio`）
  - 輪の色は4bの光の点と同じ青白（輪が4bの惑星の光だとつながるように）。視野の中の太陽のにじみは輪が埋もれないよう0.6倍まで
  - 探査機は記号: 口径1mの望遠鏡の筒が太陽を向き、後ろに小さな金色の本体、左右の腕の先に電源（RTG）。真後ろからだと筒が円にしか見えないので、斜め上にずらした
  - 金属感を強くすると黒い宇宙を映して真っ黒になったので弱めた（metallic 0.2〜0.3）。手前左上から弱い青白の光を足して形を読ませる

### 動き（11-01の1回目。数値は `state.py` の上の方）
- 1a: 平行な光が上から伸びて（15〜75フレーム目）、届いたら集まる点が光る。終わり（160〜180）で光線が消えてレンズだけ残る
- 2a: レンズが薄れながら太陽の幅まで縮み（0〜16）、少し遅れて同じ所に太陽が現れる（6〜25）。光が上から伸びる（25〜85）。光は全部の光線で同時に伸びる（光の波面）
  - 同じ大きさのまま薄れさせると、太陽に輪がかかって土星に見えた。現れる途中の太陽は透かす（暗いだけだと黒い円がレンズと星を隠した）
  - 透かした太陽は裏側の面を描かない。描くと、裏と表が重なる順番の境目が球の上に線で出て、明るくなるにつれて動き「光が右から左へ移動している」ように見えた（ユーザー「太陽の出方が気に入らない」）
- 3a: 2aの寄りから引く（0〜75、画面の高さは対数で補間）。引き始めに b=R 以外の光線を消し（0〜20）、1本だけで「1点に集まる？」→ 75フレーム目から内側の光線を10フレームおきに1本ずつ足し、交わった所まで焦線が伸びる
- 3b: 0→548AUを一定速（0〜240、1フレーム約2.3AU。動き出しと止まりの12フレームだけなめらか）→ 548AUで止まる（240〜300）
  - テロップは「地球と太陽の距離は / 1AU」（45〜130。目盛りの「100 AU」が流れてくるとき、上へ抜ける太陽に重ならない所から）→「光が集まるのは / 548AUより先」（145〜295）
  - 最初は「1AUは / 地球と太陽の距離」を太陽で1.5秒止めて出したが「タイミングが違う」。語順もユーザーの案で「…は1AU」に（文が数字で終わり、1AU→548AUが並ぶ）。「その線が始まるのは」は、間に1AUが入ると「その」が何を指すか分からない
  - ボイジャー1号（172AU、JPL Horizons 2026-11-01）を海王星と同じ書き方の目印に（ユーザー「1AUの距離感がわからない人がほとんど」）
- 4a: 30フレームは点だけ → 太陽の点から視野がピュッと開く（30〜46、行きすぎて戻る）→ 光の輪が灯る（50〜70）
- 4b: 光の点（0〜100）→ 粗いモザイクに切り替え、4→8→…→1000画素四方へ細かくなる（100〜180）
- 4c: 星だけの宇宙（暗転 →「真っ暗はどうだろう」→ 3aの引きの絵 →「ただの宇宙でいい」）
- 4bのテロップ: 「ふつうの望遠鏡では / 点にしか見えない」→「太陽を使えば / 大陸まで見える」。絵（光の点 ↔ 大陸の見える地球）と同じ対
  - 経緯: 「月より大きい鏡が / 要る」→「口径1mで / 100万画素」は「ピンとこない」（口径は普段使わない、100万画素はスマホより少なく聞こえる）→「1mの鏡で / 大陸まで見える」→ ユーザー「普通なら点にしか見えないが…、SGLなら…、の方が良くない？」。名前は4cまで出さないので「SGLなら」でなく「太陽を使えば」
  - 月より大きい鏡（約3800km）・口径1m・100万画素は投稿文に前提つきで
- テロップ: 上から約11%、行ごとに0.25秒ずつ遅れて出る、0.4秒のフェード。4cの名前だけ画面の真ん中に1.2倍で（説明のテロップと区別して名前の発表に。ユーザー「最後のテロップだけ中央に位置変える？」）

### 1aのレンズ（11-01）
- 線だけの断面図（真横から）。厚み200px（幅920px）、両端の尖りを切ったまっすぐな側面50px、角は丸めない。中は淡い水色で上ほど明るい
- 経緯: 「もう少しリアルにならない？」→ 立体のガラス（見下ろし、縁の光、ハイライト）→ 黒い背景ではガラスに映るものがなく、灰色の円盤や白い光の玉になった → スタジオの写真や自作の照明を映り込みに使い、ガラスらしくはなった →「レンズ感出さなくていいよ、線だけでいい」「厚みをつけて枠なしの虫眼鏡っぽく」「少しレンズっぽく見える色に」「角を丸めて」→ 並べて見て「角ありでゴー」
- 2aの頭: レンズが薄れながら太陽の幅まで縮み、同じ所に太陽が現れる（太陽は暗いうちは透かす）

### 目盛りと目印の大きさ
- 目盛りの数字・目印の名前は42px（`scene.LABEL_PX`、最初は26pxで「小さすぎて見えない」）。目盛りの線は長い方28px・太さ3px、短い方12px・2px
- 海王星は半径32px、ボイジャー1号は半径7pxの点＋にじみ。どちらも軸の左220px
- 目印を足す案（冥王星、太陽圏の果て約120AU、光で1日・2日・3日）も出したが「そのままでいいや」。ボイジャー1号より先に実在の物はない（人工物では一番遠い。天体は今いちばん遠いものでも約130AU）

### 参考画像から使うもの・使わないもの
- 使う: 黒背景・まばらな星、細い金色の発光線、軸に沿って下へ明るくなる線、太陽のオレンジ（`ref_1_line_a` が本命）
- 使わない（物理として違う）:
  - 太陽の上で、光線が外へふくらんで避ける形
  - `ref_3_descent` の、横から急な角度で1点に集まる絵（見かけの角度は約14°で、548AUで交わるのは一番内側の光線だけ）
  - `ref_4_probe` の、探査機の下にある惑星（系外惑星は太陽の向こうにあり、探査機は太陽の方を向いて受ける）

## 数字と出典（画面に出すもの）

| 数字 | 根拠 |
|---|---|

| 100万画素・口径1m | Turyshev & Toth, MNRAS 515, 6122 (2022)（arXiv:2204.04866）。4.2光年に地球と同じ惑星を仮定、望遠鏡は1200AU、SNR>10、約14か月（本文4.3節では約1.2年） |
| 月より大きい鏡（口径 約3800km） | 同論文1章の式（30pcの地球を1画素で見るのに口径約88.5km、N画素ならN倍）を、4.2光年・1000画素に当てはめた**制作側の計算**。月の直径約3476km は NASA Moon Fact Sheet（赤道半径1738.1km）。画面には「月より大きい鏡」だけ出し、3800kmは投稿文へ |
| 海王星（目印のみ） | 約30AU、NASA NSSDC |

- 投稿文に回すもの: 1200AU・約14か月・仮定の惑星、3800kmの計算、角度の誇張・本数の間引き、テクスチャと星図のクレジット

## 気づいたこと（完成時に教訓へ移す候補）

- 台本の誇張率（1万倍）は、画面で描いてみるまで良し悪しが分からなかった。着手前の2Dスケッチで3万倍に決められた
- 横方向だけ誇張した絵では、太陽の大きさと光線の曲がり方・海王星の距離が同時には合わない。カットごとに何を合わせるか（交わる位置は計算どおり、太陽は記号）を決めておく
- 台本の段階で「何ができるのか」（オチの具体的な数字）が抜けていた。ユーザーの一言で足した。仕組みの話だけでは、オチが名前だけになる
- 地球の向きのような、視聴者の居場所が関わる見た目は、最初から視聴者（日本）の側で決める（ただし最後は「未知の惑星感」を優先して架空の惑星にした）
- 見た目の質感の相談（「リアルにならない？」）は、静止画を1枚ずつ見せて決める。言葉で「リアル」を詰めると、作る側は立体・材質に進みがちだが、ユーザーが欲しかったのは形（厚み・側面）と色だった
- ドラフトを見せたら「説明が足りない」所が出た（レンズと重力のつながり、AUの距離感）。作る側は仕組みを知っているので気づきにくい。言葉を足すだけでなく、絵（レンズが太陽に変わる、知っている物の目印）でつなぐ
- 「その場から見た景色」のカットでは、記号の大きさが嘘になる。4aで太陽を円盤に描いたが、1200AUでは点。見かけの大きさを計算してから描く（2a・3aのような模式図とは扱いを分ける）
