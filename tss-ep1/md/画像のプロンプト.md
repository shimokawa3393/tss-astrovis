# TSS ep1 参考画像のプロンプト

見た目の方向を決めるための参考画像（AIの画像生成用）。縦型 9:16。
絵作りは「スタイライズ3D」: 黒背景、光線は発光する細い線、太陽は単純な球、軸は薄い縦線。構図は軸を縦にとる（上から光 → 上寄りに太陽 → 下へ焦線）。

AIの絵は物理として間違っていることがある（ep5の教訓）。光線の曲がり方・交わる位置は計算層（`physics.py`）で決めるので、参考画像からは**色・線の細さと光り方・暗さ・空間の奥行き**だけを使う。
